# MemoryVoice MVP

## User journey

1. Open MemoryVoice.
2. Start a voice recording.
3. Stop the recording.
4. Transcribe the recording.
5. Use AI to extract a title, people, places, dates, events, and important details.
6. Save the memory.
7. Browse saved memories.
8. Ask a question that retrieves a relevant memory.

## MVP screens

- Home
- Record
- Processing
- Memory detail
- Memory library

## Out of scope

- Accounts and authentication
- Payments
- Public sharing
- Social profiles
- Mobile apps
- Calendar integrations
- WhatsApp integrations
- Voice cloning
- Complex administration
